# LoveGirl UI 还原执行提示词 v2

你现在不是自由发挥的设计师，你的任务是把 LoveGirl 的 Flutter 界面，尽量还原成我已经确认过的参考图风格与结构。

## 核心目标

以这张参考图作为首页母版：

`C:\Users\DKX\Downloads\首页B回忆票根版.png`

如果工作区内有副本，也以它们作为辅助参考：

- `D:\lovegirl_flutter\docs\ui\home-b-memory-ticket-reference.png`
- `D:\lovegirl_flutter\docs\ui-reference-confirmed-v3.22.png`

你的目标不是“做一个差不多的暖色首页”，而是：

1. 保留这张图的版式关系
2. 保留这张图的信息层级
3. 保留这张图的票根感、奶油纸感、轻复古感
4. 不要额外加参考图里没有的大模块
5. 所有可见文字必须是中文，不能出现英文占位或乱码

## 首页必须还原的结构

首页只保留以下 5 个主区域，顺序不能乱：

1. 顶部标题区
2. 「今天想照顾的事」大票根卡
3. 回忆票根卡
4. 旅行计划票根卡
5. 生活摘要卡

禁止额外加入这些内容：

- 成就列表
- 快捷入口九宫格
- 大段说明文案
- 营销感横幅
- 和参考图无关的悬浮卡片

## 顶部标题区要求

- 左侧是超大号 `LoveGirl`
- 第二行是 `我们在一起的第 X 天`
- 数字天数用暖珊瑚色强调
- 右侧不是独立天气大卡，而是紧凑信息区
- 右侧需要同时容纳：
  - 天气
  - 体感温度
  - 爱心豆余额
- 不要在标题区再加一句口号文案

## 「今天想照顾的事」卡要求

- 必须是首页最强视觉中心
- 卡片感觉像柔软票根，不是商务面板
- 标题必须是 `今天想照顾的事`
- 副标题必须是偏情绪化的短句
- 右上角要有轻装饰，接近参考图那种花束 / 信纸 / 小贴纸气质
- 卡片内部必须左右两栏：

左栏：
- 标题 `投喂她`
- 商品名称
- 店铺名
- 状态标签（如待接单）
- 价格
- 一句偏照顾感的小提示
- 一个去查看的入口

右栏：
- 标题 `待办清单`
- 完成进度
- 至少 2 条待办表现
- 一个绿色主按钮

## 回忆票根卡要求

- 整体必须像票根，不像普通卡片
- 左侧有照片区域
- 中间是回忆标题、描述、时间关系文案（如“3个月前的今天”）
- 右侧是日期和按钮
- 按钮文案是 `生成回忆票根`
- 不能把它做成普通相册卡片

## 旅行计划票根卡要求

- 必须保留票根 + 路线感
- 左侧显示旅行主题和两人同行信息
- 中间要有路线感视觉元素，例如虚线、路径、飞机、连接线
- 右侧要有：
  - 路线状态
  - 进度条
  - `查看路线` 按钮
  - 条码感元素
- 视觉上要让人联想到“出发前规划路线”，不是普通列表卡

## 生活摘要卡要求

- 仍然是一张大卡，内部左右分栏
- 左栏偏记账
- 右栏偏课程 / 生活安排
- 不能再往下叠很多碎卡
- 这一块的作用是收尾，不是抢主视觉

## 色彩要求

- 主色：暖珊瑚棕，不要粉得发腻
- 辅色：鼠尾草绿 / 柔和植物绿
- 背景：奶油白、暖纸色
- 强调色：焦糖杏色

建议色值：

- 主色 `#B85C38`
- 主浅色 `#D4876B`
- 辅色 `#7A9E7E`
- 背景 `#FFF9F5`
- 暖纸色 `#FFF5EC`
- 强调色 `#E7B78A`
- 分割线 `#EAE4DC`

## 视觉气质要求

- 精致
- 温柔
- 专属
- 像在翻一份私人菜单或旅行票根册
- 不能太花哨
- 不能像办公软件
- 不能像通用 Flutter 模板

## 控件风格要求

- 圆角要柔和，但不要过圆
- 图标风格要更现代，不能土
- 按钮尺寸克制，不要粗笨
- 卡片阴影很轻，只做层次，不做悬浮感堆叠
- 文本全部使用中文
- 票根卡允许有切角、缺口、分隔线、条码等元素

## 开发约束

- 基于现有 Flutter 项目实现
- 不要擅自重构整个导航结构
- 不要为了“统一”把别的页面也改成另一套完全不同的风格
- 不要添加参考图之外的新模块
- 先让首页高度接近参考图，再处理别的页面延展

## 结果标准

只有当下面这些都成立时，才算完成：

1. 用户打开首页第一眼，结构和参考图高度一致
2. 不再出现英文占位和乱码
3. 天气和体感温度不会溢出边框
4. 没有多余模块破坏首页节奏
5. 整体看起来像情侣专属 App，不像后台系统
