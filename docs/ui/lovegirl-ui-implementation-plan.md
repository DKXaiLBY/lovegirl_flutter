# LoveGirl UI 落地任务与验收标准

更新时间：2026-07-03

## 已确认设计基准

- 首页基准图：`docs/ui/home-b-memory-ticket-reference.png`
- 其他界面延展图：`docs/ui/ui-board-feeding-travel-profile-v1.png`
- 我的页资料夹版：`docs/ui/profile-folder-ui-v1.png`

## 总目标

把 LoveGirl 的 UI 从“功能入口集合”统一成“奶油纸张 + 回忆票根 + 专属菜单 + 真地图产品”的情侣 App 体验。页面要温暖、精致、干净，但不能粉腻、花哨或像办公软件。

## 当前阶段范围

### P0

- 修复核心入口、首页、我的页的可见中文乱码。
- 重写全局主题颜色、圆角、阴影、底部导航样式。
- 建立可复用的纸张卡片、票根卡片、胶囊标签、菜单行组件。
- 首页按“首页 B 回忆票根版”落地：恋爱天数、天气体感、今日事项、回忆票根、旅行计划、常用入口。
- 我的页按“我们的小资料夹”落地：恋爱档案、偏好设置、数据与安全、关于 LoveGirl。

### P1

- 投喂站列表和商品详情继续改成“专属菜单”风格。
- 旅行地图浮层继续改成“真地图 + 底部票根详情”风格。
- 纪念日、生活模块、聊天等页面逐步替换乱码文案和旧卡片样式。

### P2

- 根据真机截图继续调密度、字体层级、底部导航图标。
- 为旅行票根和月度报告补充更完整的视觉模板。

## 验收标准

- 首页第一屏接近保存的“首页 B 回忆票根版”，不出现旧版大色块和乱码。
- 我的页不再是功能看板，而是清晰的情侣资料夹。
- 天气组件显示体感温度，加载失败时有中文可理解提示。
- 底部导航中文正常，图标风格统一。
- `flutter analyze --no-pub` 不出现由本轮 UI 修改新增的编译错误。

## 暂不处理

- 不在这一小步里重写投喂站后端、旅行地图高德 SDK 接入、版本发布流程。
- 不提前构建正式 APK；等 UI 页面完成并通过检查后再构建。
