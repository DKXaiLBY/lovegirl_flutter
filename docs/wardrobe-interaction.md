# 电子衣柜 · 交互逻辑全量说明

版本：v0.9（平台无关——LoveGirl 内嵌 / 独立 App / 小程序通用）
日期：2026-09-27
配套：docs/wardrobe-prd.md v0.95

> 本文档逐条列出衣柜模块每一个页面、每一条交互路径、每一个边界情况。
> 平台差异只影响"入口挂载位置"，不影响页面内部逻辑。

---

## 0. 全局约定

- **导航骨架**：底部两Tab「衣橱」「穿搭」+ 右上角「+」全局添加按钮
- **空态**：每个列表页必须有插画空态 + 引导按钮（衣橱空→"放入第一件"；穿搭空→"记录今天穿了什么"）
- **图片**：所有上传图 App 端先压长边 1600px；失败可重试；上传中禁止重复提交
- **删除**：一律二次确认弹窗；被引用的资源提示引用数
- **手势**：列表项点击=进详情；长按=进多选/快捷菜单
- **单位与日期**：价格 ¥ 元；日期一律精确到日；今天判定按本地时区

## 2. 逐页交互逻辑

### P1 衣橱主页

进入态：
1. 无单品 → 空态插画 +「放入第一件衣服」按钮 → P2
2. 有单品 → 网格（2列）按类型分组：上装 / 裤装 / 裙装 / 外套 / 鞋子 / 包袋 / 配饰 / 连体装，每组一行组头+横向网格

交互：
- 点击单品卡 → P3 单品详情
- 长按单品卡 → 进入多选模式（底部浮出：加入搭配 / 退役 / 删除）
- 点击筛选按钮 → P10 筛选面板（半屏上滑）
- 点击「+」→ 弹出二选一：添加单品 / 创建搭配
- 顶部胶囊（有伴侣时）：我的衣橱 ⇄ TA的衣橱（只读，TA的卡不进多选）
- 在洗/收纳的单品：正常显示但卡片左上角有小标；退役的不出现（筛选器可勾选查看）

### P2 添加单品（流程）

步骤：
1. **取图**：拍照 / 相册选图（1张主图）→ 进入裁剪预览
2. **抠图（可选开关）**：默认开 → 服务端去背景出透明PNG → 用户看"原图/抠图后"对比，可点"保留原图"跳过 → 不满意可重抠
3. **填标签表单**：
   - 类型（单选，8类，必填，默认按上次选择记忆）
   - 温度（单选4档，选填）
   - 场合（多选，选填）
   - 风格（多选，选填）
   - 颜色（单选，选填）
   - 品牌（选填文本）
   - 价格（选填数字，¥）
   - 状态（默认在柜）
4. **保存**：校验类型必填 → 上传 → 成功回 P1 并滚动到新单品

边界：
- 抠图服务超时/失败 → toast"抠图失败，已保留原图"，流程不中断
- 取消退出：任何步骤返回 → 弹"放弃添加？"确认（已有图片上传时）
- 无网络 → 图片存本地待上传队列？**不做**，直接报错重试（保持简单）

### P3 单品详情

- 大图（可点开全屏）+ 全部标签 + 品牌/价格 + 状态 + 穿着次数 + 关联穿搭列表（点击跳 P9）
- 右上编辑 → P4
- 底部操作条：「加入搭配」（跳 P5 且预选此件）/「标记为」（在洗/收纳/退役 快捷菜单）
- 删除在 P4 编辑页内（二次确认 + 提示"影响 N 条搭配"）

### P4 编辑单品

- 同 P2 表单，预填现值；图片可换（换图重新走抠图）
- 删除按钮在底部（红字，二次确认）
- 保存 → 回 P3

### P5 组合搭配创建

入口：主页「+」→创建搭配；或单品详情「加入搭配」预选一件
1. 选件面板：按类型分节列出我的在柜单品（默认隐藏在洗/收纳/退役），点选加入
2. 已选托盘：屏幕底部横向显示已选单品缩略图（≤8件），点缩略图可移除
3. 校验：至少 2 件才可保存（1件不叫搭配）
4. 保存时填：穿着日期（默认今天，可改未来=计划穿搭）、备注
5. 保存后状态 = **待确认** → 回 P7 时间线并置顶新记录

边界：
- 从 P3 带入预选件时，该件已选中状态
- 保存为"草稿"？不做——状态只有 待确认/已通过，退回即回到编辑态

### P6 实拍记录

入口：穿搭Tab「+」→ 记录今天穿搭
1. 拍照/选图（1张）
2. 填：穿着日期（默认今天）、备注（选填）、可选关联衣柜单品（跳过也可）
3. 保存 → 状态直接 = **待确认**（与组合搭配一致，进自我评价流）

### P7 穿搭时间线（穿搭Tab默认页）

- 按穿着日期倒序分组：今天 / 昨天 / 本周 earlier / 更早
- 每条：封面图 + 来源标（实拍/组合 + 组合显示单品缩略图叠排）+ 状态标（待确认=橙点 / 已通过=绿勾）+ 备注
- 顶部「月历」切换 → P8
- 点击条目 → P9 穿搭详情
- 长按条目 → 快捷菜单：改为已通过 / 删除
- 空态 → 「记录今天穿了什么」

### P8 穿搭月历

- 标准月历网格，有穿搭的日期显示小圆点/缩略图角标
- 点日期 → 当天穿搭列表（0/1/多条）
- 月份左右切换；未来日期不可点（无记录）

### P9 穿搭详情

- 大图（实拍）或组合单品横排（组合）
- 元信息：穿着日期、来源、状态、备注、关联单品列表（点击跳 P3）
- 操作：
  - 待确认态：「通过」按钮（变已通过）/「继续编辑」（回编辑态改日期/备注/单品）
  - 已通过态：可改回待确认（误操作回退）
  - 删除（二次确认）
- 编辑仅允许改：日期、备注、关联单品、换图；状态流转按上

### P10 筛选面板

- 维度行：温度（4选1）/ 类型（8选1）/ 场合（多选）/ 风格（多选）/ 颜色（单选）/ 状态（在柜等，多选）
- 「重置」「应用」；应用后 P1 网格即时过滤 + 顶部显示当前筛选条件胶囊（可单个移除）
- 结果为 0 → 网格区显示"没有匹配的衣服"+「清除筛选」

### P11 TA 视角（情侣）

- 有伴侣时 P1/P7 顶部出现"TA的"切换
- TA的衣橱：只读网格，可看详情，不能编辑/删除/多选
- TA的穿搭：只读时间线
- TA 发起的搭配在我的时间线中带"TA 搭的"角标（P1 迭代：TA 可发起搭配给我确认——本期只做自我评价，TA 仅只读）

## 3. 状态机

### 单品状态
```
在柜 ⇄ 在洗
在柜 ⇄ 收纳
任意 → 退役（不进默认列表，可恢复）
退役/在柜 → 删除（物理删，引用标记）
```

### 穿搭状态
```
创建(实拍/组合) → 待确认 ⇄ 已通过
待确认/已通过 → 编辑（原地改，不改状态）
任意 → 删除（二次确认）
```

## 4. 边界与异常清单

1. 删除被 N 条穿搭引用的单品 → 确认弹窗"该单品出现在 N 条穿搭中，删除后这些穿搭将显示「单品已删除」占位"
2. 同一天多条穿搭 → 允许，时间线同组展示
3. 组合里含已删除单品 → 缩略图位置显示灰占位+名字删除线
4. 上传中断网 → 报错重试按钮，表单内容保留
5. 抠图失败 → 保留原图继续流程（见 P2）
6. 日期选未来（组合计划）→ 允许；月历未来日期显示空心标记（计划）
7. 穿着次数统计口径：穿搭（组合）每次通过即计关联单品各+1；实拍不计数（无关联）
8. 无伴侣：隐藏一切 TA 元素
9. 多选模式下的系统返回键 → 先退多选，再按才退页面

## 5. 字段校验表

| 字段 | 必填 | 规则 |
|---|---|---|
| 单品主图 | 是 | ≤10MB，jpg/png/webp |
| 类型 | 是 | 8枚举 |
| 温度/颜色/状态 | 否 | 单选枚举 |
| 场合/风格 | 否 | 多选枚举 |
| 品牌 | 否 | ≤20字 |
| 价格 | 否 | ≥0 数字，2位小数 |
| 穿搭日期 | 是 | 2000-01-01 ~ 今天+90天 |
| 穿搭组合件数 | 组合时≥2 | ≤8 |
| 备注 | 否 | ≤200字 |
