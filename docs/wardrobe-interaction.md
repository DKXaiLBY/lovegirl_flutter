## 0. 全局约定

- **导航骨架 [V]**：生活 tab 内子模块。页顶第一行：分段切换「**衣橱｜穿搭**」（左）+「**＋**」添加按钮（右）——不用底部双 Tab（与全局五 Tab 冲突）
- **TA 切换**：有伴侣时，分段控件下方一行居中胶囊「我的 ⇄ TA 的」（两个分段共用），无伴侣时隐藏
- **空态**：每个列表页插画空态 + 引导按钮（衣橱空→"放入第一件"；穿搭空→"记录今天穿了什么"）；插画 M1 素材前置（见 §5 素材）
- **图片**：上传前 App 端压长边 1600px；**主图强制 1:1 方形裁剪**（可微调裁剪框），详情页点开看原图 [R3]
- **删除**：一律二次确认；被引用资源提示引用数
- **手势**：点击=进详情；长按=进多选/快捷菜单；多选模式下系统返回键先退多选
- **日期/货币**：日期精确到日本地时区；价格 ¥ 元两位小数

## 2. 逐页交互逻辑

### P1 衣橱主页 (M1)

进入态：
1. 无单品 → 空态插画 +「放入第一件衣服」→ P2
2. 有单品 → **按类型分 8 个小节**（上装/裤装/裙装/外套/鞋子/包袋/配饰/连体装），每节=节头（类型名+数量）+ 2 列网格；**节内排序=添加时间倒序** [R2]

交互：
- 点击单品卡 → P3；长按 → 多选模式，底部浮出菜单：**加入搭配 / 退役 / 删除** [R4]（批量打标签 M2 后再说）
- 点击筛选按钮 → P10；**筛选栏旁常驻"今天胶囊"**：「今天 26°C · 温暖 → 一键筛出适配单品」（数据取首页天气，点击=应用温度筛选）[Q6]
- 点击「＋」→ 二选一：添加单品 / 创建搭配
- TA 胶囊切到"TA 的"→ 只读网格（可看详情、可用筛选，不进多选）
- 在洗/收纳单品正常显示带角标；**退役不出现**（筛选器可勾选查看）；**v1.0 状态仅 在柜/退役 两态，在洗/收纳 M2** [R5]

### P2 添加单品流 (M1)

1. **取图**：拍照/相册选 1 张主图 → 1:1 裁剪
2. **抠图（默认开）[Q5]**：服务端去背景 → 用户看"原图/抠图后"对比，可"保留原图"跳过、可重抠；**降级闸**：M1 上线前先在服务器实测 U2Net（2 核/1.6G 内存紧），超 3 秒或 OOM 自动降级为"仅压缩不去背景"，服务端开关可远程关闭
3. **表单**：类型（必填，记忆上次选择）/ 温度 / 颜色 / 状态（默认在柜）单选；场合 / 风格多选；品牌 ≤20 字、价格 ≥0 选填
4. **保存** → 回 P1 并滚动定位到新单品

边界：抠图失败/超时 → toast"抠图失败，已保留原图"，流程不断；中途返回 → 有图时弹"放弃添加？"；断网 → 报错重试，表单保留（不做本地上传队列）

### P3 单品详情 (M1)

大图（可全屏）+ 标签 + 品牌/价格 + 状态 + **穿着次数** + 关联穿搭列表（点击跳 P9）
- 右上编辑 → P4；底部「加入搭配」（跳 P5 预选此件）/「标记为」（快捷改状态）
- 删除在 P4 内（确认 + 提示"影响 N 条搭配"）

### P4 编辑单品 (M1)

同 P2 表单预填；换图重走裁剪+抠图；底部红字删除（二次确认）

### P5 组合搭配创建 (M1)

1. 按类型分节列出**在柜**单品点选加入
2. 底部已选托盘：横向缩略图 ≤8 件，点缩略图移除
3. 校验：**≥2 件**才可保存
4. 填：穿着日期（默认今天，**可选未来=计划穿搭** [Q4]）、备注
5. 保存 → 状态=**待确认** → 回时间线置顶

### P6 实拍记录 (M1)

拍照/选图（1 张）→ 填日期（默认今天）、备注 → **可选关联衣柜单品** → 保存
**[V] 状态=已通过**（实拍是"已经穿了"的事实记录，无需自我评价；可改回待确认）——与 v0.9 不同

### P7 穿搭时间线 (M1)

- 分组：**计划中**（未来日期，置顶，最近优先）[Q4] / 今天 / 昨天 / 本周更早 / 更早
- 每条：封面（实拍图或组合单品缩略图叠排）+ 来源标 + 状态标（待确认=橙点/已通过=绿勾/计划=蓝钟）+ 备注
- 点击 → P9；长按 → 快捷菜单（改为已通过 / 改回待确认 / 删除）
- 顶部「月历」入口 → P8（M2）；空态 →「记录今天穿了什么」

### P8 穿搭月历 (M2)

月历网格；有穿搭的日期显示角标缩略图；**未来日期有计划的显示空心标记、可点** [Q4]；点日期 → 当天列表

### P9 穿搭详情 (M1)

大图 / 组合单品横排（**含已删除单品的灰占位+删除线名**）+ 日期/来源/状态/备注/关联单品（点击跳 P3）
- 待确认：「通过」/「继续编辑」；已通过：可改回待确认；计划：可改日期
- 编辑可改：日期、备注、关联单品、换图；删除二次确认

### P10 筛选面板 (M1)

维度：温度（单选）/ 类型（单选）/ 场合（多选）/ 风格（多选）/ 颜色（单选）/ 状态（多选，v1.0 只有在柜/退役）
「重置」「应用」→ P1 即时过滤 + 顶部条件胶囊可单个移除；结果 0 → "没有匹配的衣服"+「清除筛选」；TA 视角下筛选器同样可用（只读）

### P11 TA 视角 (M2)

- TA 的衣橱/穿搭：**只读**，可用筛选器；**待确认/已通过/计划 全部可见** [Q7]
- **[V] TA 发起搭配延后到 M2 后期**：与"自我评价"状态流有归属冲突（TA 搭的算谁的待确认？），v1.0 先跑通单人闭环（旧会话拍板"TA 可发起搭配"不缩水，只是顺延）
- 无伴侣：隐藏一切 TA 元素

## 3. 状态机

```
单品：在柜 ⇄ 退役（v1.0）；在洗/收纳 M2 加入
      退役/在柜 → 删除（物理删，穿搭内引用变占位）
穿搭：实拍 → 已通过（默认）⇄ 待确认 [V]
      组合 → 待确认 → 已通过（自我评价）
      日期在未来 = 计划（叠加显示，非独立状态）
      任意 → 编辑（原地改）；任意 → 删除
```

## 4. 边界与异常（v1.0 终版）

1. 删除被引用单品 → 确认弹窗"出现在 N 条穿搭中"，穿搭内变灰占位
2. 同一天多条穿搭 → 允许，同组展示
3. 组合含已删除单品 → 灰占位+删除线
4. 断网 → 报错重试，表单保留
5. 抠图失败/超时/OOM → 保留原图继续；服务端可远程关开关（降级为仅压缩）
6. 未来日期 → 允许（计划）；月历可点；时间线"计划中"分组
7. **穿着计数 [R1]**：组合**通过时**关联单品各 +1，改回待确认/删除时 -1（wear_count 冗余列事务更新）；实拍**关联了单品**的，通过即计数，未关联不计
8. 无伴侣 → 隐藏 TA 元素
9. 多选模式系统返回 → 先退多选
