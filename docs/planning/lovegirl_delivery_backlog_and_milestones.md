## 3. 优先级规则

### P0：不做就不能发布

- M1 工程基线清理
- M2 设计系统统一
- M3 首页重构
- M4 投喂站主链路重构
- M5 旅行地图主链路重构
- M6 我的页重构
- M9 联动与爱心豆
- M10 后端统一与迁移
- M11 对抗式审查
- M12 真机验收与发布

### P1：重要，但可以晚于主链路稳定

- M7 生活域收口
- M8 回忆域收口

## 4. 依赖关系

- M2 依赖 M1
- M3 / M4 / M5 / M6 依赖 M2
- M7 / M8 可以穿插，但不应早于 M2
- M9 依赖 M4 / M5 / M7 / M8 至少部分完成
- M10 贯穿全程，但在发布前必须收口
- M11 依赖主要业务完成
- M12 依赖 M11

## 5. 发布门槛

在下面这些条件都满足前，不允许构建正式发布版：

- 核心页面 UI 验收通过
- 中文乱码问题已清理
- 高德真地图真机不崩
- 投喂站主链路可用
- 核心联动成立
- 对抗式审查 P0 清零
- 服务器部署版本正确
