# LoveGirl 实现证据模板

更新时间：2026-07-17
适用阶段：从 `M1` 开始进入实现后，用于统一记录各阶段完成证据

## 1. 这份文档的定位

前面的文档已经明确了：

- 每个里程碑要交什么
- 每个里程碑什么情况下能退出
- 没有证据不算完成

这份文档补的是最后一块：

**证据该怎么记。**

它不负责定义方向，也不负责拆任务，只负责给后续实现、审查、真机、发布留下统一记录格式。

## 2. 使用原则

### 2.1 一次实现，一次留痕

每完成一个明显阶段，都应该留下至少一份标准化记录。

### 2.2 模板可以裁剪，但不能失真

不要求每次都把所有栏位写满，但不能把关键证据省掉。

### 2.3 优先记录“可复核事实”

优先记录：

- 改了哪些文件
- 用什么方式验证
- 结果是什么
- 还剩什么风险

少写空泛结论。

## 10. 推荐使用顺序

如果后续正式切入实现，建议这样配合：

1. 用 [lovegirl_master_delivery_control_board.md](D:/lovegirl_flutter/docs/planning/lovegirl_master_delivery_control_board.md) 判断当前阶段该交什么
2. 用本文件里的模板记录阶段证据
3. 用对应执行包判断下一步去哪里

## 11. 结论

这份模板文档的作用很简单：

- 不让证据记录继续凭临场发挥
- 不让阶段完成判断只靠口头描述
- 让 LoveGirl 后续真正进入实现时，能留下可复核、可交接、可回看的实施痕迹
