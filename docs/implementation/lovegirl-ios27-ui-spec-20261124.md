# LoveGirl 全局界面改版规格

2026-11-24 · 底部导航方案已确认 · 视觉、动效及验收设计待审阅

正式基线为 v4.8.2+198，源码提交 `1333282`，回滚分支
`backup/before-ios27-ui-20261124`。以手机竖屏为首轮验收尺寸，平板按可用宽度调整内容排列。

## 导航与常用路径

| 入口 | 第一屏 | 常用路径 |
| --- | --- | --- |
| 今天 | 关系摘要、天气、最相关的一件事和近期内容 | 「继续备考」进入当前账号可见的讲义或备考首页。顶部带「我们」语义标签的头像打开关系、邀请、账号和设置。 |
| 回忆 | 最近的相纸与票根、月份和记录入口 | 横滑相纸可以停在任意位置。点一张相纸绕纵轴翻到背面。票根和相纸详情能回到原来的月份和滚动位置。 |
| 旅行 | 可操作的街道地图和当前地点 | 搜索、定位和行程保留清楚的入口。选中地点显示照片浮卡。退出详情后恢复地点、地图视野和行程选择。 |
| 生活 | 点菜、待办、备考和已授权的常用工具 | 当天有订单时先显示状态和下一步。更少使用的工具聚在「全部工具」。厨房流程按菜单、订单、开饭组织。 |

从首页的头像进入「我们」后，「设置 → 检查更新」仍可操作。返回与系统返回键遵循同一层级，关注正在编辑的内容和当前账号权限。实际可到达的二级及更深页面按阅读、详情、编辑和设置整理。导航映射按入口标识维护。

## 界面与动效

| 场景 | 样式与反应 |
| --- | --- |
| 底部栏与浮动导航 | 保留克制的高光和清透边缘。选中态用位置、轮廓和文字共同表达，轻微移动选中底座。滚动时标签位置稳定，所有入口始终能直接点击。 |
| 正文、编辑、答题、设置 | 使用高对比的实色内容面，统一字阶、间距、焦点和禁用态。备考保留深蓝书刊和宋体。长选项纵向换行，提交反馈与答案出处相邻。 |
| 照片和票根 | 照片保留相纸厚度、接触阴影和翻面透视。票根由票面材质、打孔和留白体现实物感。作品高光随操作变化。 |
| 地图、行程和地球 | 导航按钮、路线信息、位置和方向优先可辨。照片浮卡随选择更新；行程列表与地图选中状态保持一致。以地图及已访问地点作为主要视觉内容。 |
| 按钮、弹层与页面返回 | 按压时即时变色或微缩，提交中和完成态在原位置反馈。弹层和详情按打开方向进入，返回恢复上下文。操作控件沿用同一套图标和可读标签。 |
| 减少动效、触觉和高对比 | 系统或 App 关闭动效时，翻面与页面仍可立即完成切换。震动独立遵循设置。深色、高对比和地图亮背景下确保文字与按钮边缘可见。 |

Flutter 的共用主题、导航控件和弹层作为迁移入口。地图原生视图只在需要展示时挂载，切换入口保存轻量视野状态。常用动效优先变换与透明度。把玻璃滤镜限制在小范围导航层，内容列表直接绘制。

按压、弹层和相纸翻面的起始时长分别为 90–120 ms、180–240 ms 和 280–360 ms，根据真机操作调整。侧滑返回和相纸横滑优先跟随手指，刷列表时保留已有内容，加载状态只放在受影响的位置。

## 实施与检查顺序

1. 保存 v4.8.2 正常状态的荣耀截图和任务路径。在受控账号核对从首页复习、查找位置、打开作品和点菜的实际入口。
2. 改底栏、首页动作和关系入口，验证目标页、系统返回、通知跳转、账号切换，以及登录和断点续传。
3. 应用共用样式与动效，逐页核对回忆、票根、旅行、行程、生活、厨房和备考，将设置、表单、弹层及更深的业务页纳入同一清单。
4. 用同一台荣耀、同一批数据对比改版前后截图和操作录屏。确认实际手势、性能和内容可读性后构建并发布。

## 验收标准

- 从「今天」一次点击进入备考，从底栏一次点击打开真实地图。「我们」和「检查更新」的入口能找到，返回后保留当前页和位置。
- 在 360 dp 手机宽度、默认和放大字号、亮色和深色分别验证。常用点击目标至少 48 dp，长答题选项、行程信息、错误提示和弹层行动按钮完整可见。
- 相纸自由横滑和点击翻面分别验证。检查侧边经过中间角度，再看背面内容。地图定位、选点、行程和实际导航路线通过原入口验证。
- 按压、切页、弹层、结果反馈和恢复上下文分别检查。关闭动效与触觉后重复关键操作。地图和回忆常用手势记录帧耗时，与同机基线对比。
- 首页备考按当前账号读取，照片、地点、讲义、订单和账号既有权限保持有效。大字号、加载、空、失败和重试状态均用可重复场景验收。
