# LoveGirl 4.7.0 界面分区与专升本备考

## 目标和验收内容

| 使用场景 | 验收标准 |
| --- | --- |
| 第一次使用 | 保留五个主入口。今天展示一个优先行动。生活首屏能直接点菜、看待办和打开备考。从「我们」能分辨新账号邀请和伴侣绑定。 |
| 浏览回忆 | 用「全部、照片、拍立得、票根」筛选，从一个「添加」入口开始创作。 |
| 旅行准备 | 在指定行程直接打开行李清单。新清单独立于衣橱。旧搭配可以查看和解除关联。衣橱资料可从「生活 → 全部工具」进入。 |
| 备考 | 政治理论、管理学、基础会计学使用同一录入和复习流程。讲义裁切后在 Android 本机识字，也可粘贴已有笔记。草稿附资料原文，核对后保存。 |
| 作答与隐私 | 支持回忆要点、选择、填空和简单会计分录。按结果安排下次复习。资料和进度按账号隔离，用户可主动复制单个考点供对方导入。 |
| 界面材质 | 液态玻璃仅用于底部标签栏。地图操作、筛选、内容卡、表单及弹层保持实底。浅色、深色和大字号可读。 |

题卡草稿使用笔记里的原句和本地规则。可以手动修改题目、选项、答案与出处。第一版提供科目和练习流程，内容来自用户导入的讲义和电子笔记。中国文字识别模型随 Android 安装包提供，讲义原图留在设备上，保存考点时同步校对后的文字和题目。
