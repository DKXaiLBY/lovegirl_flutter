## 范围与依据

- 主依据：`docs/design/glass-paper-20261027/02-physical-paper-reference.png`；玻璃按钮沿用 `01-clear-glass-reference.png`。两张均为生成设计图，不能当作运行效果。
- 改造拍立得浏览、背面、编辑、相纸与成像选择，以及票根模板、编辑、作品展示。旅行仅调整已有地图控件、行程卡片和交通弹层的视觉层级，沿用此前已确认布局；不重建业务。
- 相纸默认使用细密平滑的光面、窄上边与侧边、宽下沿、薄层边缘和接触阴影；织纹等独立纸款继续保留自己的材料。票根使用哑光纸、裁切、齿孔和细微折痕。
- 不改作品/草稿格式、成像算法、照片裁切坐标、联网/冲突/权限规则、接口、服务端、已有用户内容，以及其他页面的全局主题。厨房、每日一问和慢信的产品取舍留在后续任务。
- 玻璃采用范围受控的背景采样、低模糊、边缘高光和透明层，保证文字清楚；不承诺对生成图中的光线做逐像素物理模拟。移动和按压时响应，静止时不运行循环动画。

## 施工与验收

1. 备份 → 核对基线提交、bundle 可读和旧 APK SHA256。
2. 材质与控件 → 检查平滑光面/纸票区别、透亮中心/高光边缘、选中和按压反馈。
3. 页面布局 → 照片/票面占主体，减少顶部重复信息，工具收进清楚的玻璃托盘；保留全部已有操作入口。
4. 运行核验 → 使用同组受控作品，保存真实 Flutter 页面的亮/暗/窄屏截图并逐项与参考图比对；照片内容差异不当作 UI 差异。
5. 回归与发布 → analyze 无问题，现有相关测试及完整 Flutter 测试通过；在可用真机上检查手势/按压/翻面、编辑/草稿/导出与地图选择。必要验证通过后按既有授权发布，只写实际完成内容。

| 维度 | 完成标准 |
|---|---|
| 玻璃 | 背景确实透过中心；圆角边缘有高光和内侧暗缘，不能退化成白色不透明卡片加投影；深浅背景下文字和图标可辨 |
| 相纸 | 正常浏览尺寸可分辨照片光面与白边；薄边、叠放、接触/抬角阴影方向一致；默认白纸不出现粗糙水彩纹或厚塑料框 |
| 票根 | 哑光纸与相纸区别清楚，孔位/裁切/虚线准确，文字无遮挡；票面颜色与外围工作台继续分离 |
| 布局 | 浏览主体足够大；重复标题和说明不挤占画布；当前作品、月份/草稿入口、主行动容易找到 |
| 反馈 | 所有新增自绘按钮保留语义、触控面积至少48逻辑像素；按压/选中/翻面有明确反馈；减少动态设置生效，无装饰性常驻动画 |
| 适配 | 360逻辑像素宽及深浅色均无溢出、遮挡或不可读文字；键盘打开后编辑字段与提交仍可达 |
| 原有功能 | 切图/翻面/大图、手绘与裁切、相纸/成像、草稿/收藏/导出、票根换图和配色、旅行选择与排序等原流程不退化 |
| 完成证据 | 提供实际运行截图、视觉核对结果和动态实测记录；测试数量、生成图或发布成功不能代替视觉验收 |

若真机不在线或被他人同时操作，只继续不依赖手机的工作，明确记录待验项目，不宣布目标完成。
