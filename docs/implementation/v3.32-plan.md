## 批次 0：素材入库

1. 写 PIL 处理脚本 `tools/process_illus.py`（必须落盘成 .py 再跑，勿 cmd 内联）：
   - 选图：66 张候选（33 条×2），默认选 `_1`，之前标注"贴边裁切"的条目选 `_2`
   - 白底转透明（近白阈值→alpha 0，边缘保留抗锯齿）→ 裁掉透明边 → 最长边压到 512px → PNG optimize

2. `pubspec.yaml` **显式声明** `assets/images/illus/`（子目录坑，教训 #2）
3. `.gitignore` 追加：`assets/images/illus_raw/`（18 张参考原图）、`assets/images/illus_gen/`（66 张原始候选，只入库处理后的正式资产）；脚本入库需 `git add -f`（全局 `*.py` 规则，教训）
4. emoji→插画替换：执行时先 grep 全 App emoji 使用点，对照素材清单（天气 4/空状态 6/倒计时卡 6/纪念类型 4/UI 用图 6 等）出替换映射，逐点换成 `Image.asset`；只换固定 UI 点位，不碰用户输入文案。附带收益：老设备 emoji 豆腐块坑（教训 #3）自动消除

## 发版与备份回滚

**备份（改代码前就位）**
- App：当前 HEAD 打 tag `pre-v3.32`；每批次独立 commit push（天然回滚点）；发版后打 tag `v3.32.0-release`
- 服务器：动 voucher 路由前，live 快照 tar 存 `docs/server-snapshots/` + 服务器 git 基线 commit（有脏工作区先提交干净）
- APK：`D:\lovegirl_build\releases\` 建发布留档目录，本版 apk 带版本号存入；现 build 目录若为 v3.31.1 产物一并归档（手机端回滚 = 重装旧 apk）

**发版**
- 版本号两处：`pubspec.yaml` → `3.32.0+161`；`lib/utils/constants.dart` versionName/versionCode 同步
- `flutter build apk --release`（不带 dart-define）→ 真机过一遍深浅两态（模拟器已过，真机快速抽查）
- POST `/api/deploy/publish`（header `x-deploy-token`，字段 apk/v/c/s/l）
- **必须修正** app_versions 表 version_name/changelog：UTF-8 SQL 文件 scp → docker cp 进容器执行，changelog 换行用 CHAR(10) 拼接；SQL 一律内联字面量 + 参数化数组形状
