## 4.5.2 实现与验收

- 用户确认复验入口为「回忆」顶部相纸。隔离账号在荣耀畅玩 20 上分别测试已发布作品、旧相册照片和长按进入的大图。`new-shelf-3d-proof.png` 是同一次首页翻面的连续取样。在斜转和近侧面画面可看到照片窗的梯形透视、纸边与收窄的落影。大图从长按时所在的一面打开，旧相册背面文字可读。
- 首页慢拖后两张相纸均留在可见范围，间隔清楚。两次静止截图中原相纸的右边界均为物理像素 x=397。点旁边旧相纸时，第一张保持背面及原位置。图库用自由滚动取代吸附和重复的底层相纸，测试验证停在半张后滚动位置保持稳定。
- 对照 `docs/design/clear-app-20261031/02-memories.png` 检查照片主次、票根位置和可读性。采用较新确认的 B 方案，背景和控件为清透材质，纸材质用于相纸和票根；两张相纸有明确间距。荣耀首屏能看到胶片边缘，完整胶片需继续向下滚动。
- 荣耀亮色下确认「今天」显示天气入口，首页无邀请按钮，「我们」可直接看到伴侣绑定；深色和减弱动效另有独立实机证据。此轮使用既有隔离数据，只执行浏览、翻面、查看大图及本机偏好操作。所有实际截图和分帧保存在源码备份目录。
- 样式复验以本轮改动的回忆入口为主。荣耀对照五个一级页的截图汇总在备份目录 `tab-reference-comparison.png`。地图验证定位后蓝色方向标可见，足迹地球可拖动旋转；行程沿用 4.5.1 的验收记录，实走中的语音和偏航按用户安排留给主力机后续使用。
- 生活页首屏对照发现，慢速图片加载时厨房封面留白，白色按钮文字难以看清。封面加载或失败时呈现已随包提供的封面，厨房入口在有封面和无网络图片时均用深色玻璃底保证白字对比度。
- 荣耀分别打开「去点菜」和「我的菜单」，落地页正确。回忆页以亮色默认字号、暗色且关闭动效、亮色 1.45 倍字号查看。关闭动效时在第一张定时采样已显示完整背面。手机恢复亮色、标准动效及 1.15 倍字号。
- 静态检查无问题。最终 Flutter 测试 263 项通过，含两类相纸在翻面中途的尺寸、图库停止位置、厨房封面等待和按钮可用性。
