## 阶段 1：情侣厨房（投喂站 2.0，完全重构）

**产品逻辑**：菜单是"我会为你做的事"。双方各自挂菜单（会做的菜），对方以外卖平台的
交互浏览下单（左分类/右菜名），接单方收到订单红点，买菜做菜后拍成品照完成订单，
自动沉淀为投喂记录 + 投喂小票票根 + 爱心豆，成品照进时光轴素材。

### 已锁定决策
| # | 决策 |
|---|------|
| D1 | 菜单双向：双方都能挂菜单、都能下单 |
| D2 | 菜品价格为趣味展示；下单免费；完成订单 +5 爱心豆 |
| D3 | 通知 = App 内红点 + 首页提示条（不做系统推送） |
| D4 | 原投喂站（商家目录+商品+记花费）UI 全部删除；服务器旧接口保留不动（兼容旧版本 App） |
| D5 | 原 shops 数据不在新 UI 中出现（不降级为常去清单，直接砍） |

### 验收条款
- [ ] A1 生活tab投喂站入口进入后，看到的是情侣厨房（菜单/订单/记录 三段式），无任何商家目录残留
- [ ] A2 菜单页左侧分类、右侧菜品列表（外卖平台交互），支持添加菜品（名称/分类/emoji或照片/趣味价/描述）
