## 范围与数据

- 省份地图 → 按城市、日期排列的记录 → 独立故事页，复用地点的照片、手记、天气和心情。
- 同城多地点统计为一座城市，未填城市不伪造城市；同日多记录保留，缺日期排最后。
- 新页采用影像日记排版。玻璃只用于操作面，正文稳定底色；保留现有省份投影、拍立得和票根形态。
- 地点照片继续使用 travel_photos。关联已有相册照片只创建引用，不复制文件；移除引用不删除相册原图。
- 通过 source_photo_id 和唯一约束防重复关联；外键使原相册照片删除时清除引用。沿用本人/当前伴侣的地点权限，相册选片沿用原相册权限。
- 首先核对线上路由与表结构；服务端连接失败时保存可测试补丁，明确报告未上线，不假报联调完成。
