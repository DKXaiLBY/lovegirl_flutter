**四、实施路线与取舍**

| 路线 | 能解决的问题 | 代价与不足 |
|---|---|---|
| 只调整页面外观 | 快速改变配色、卡片和按钮 | 无法补齐票根编辑、草稿、逐日安排、路线重算和同步，不足以满足本次核心需求 |
| 重建选定模块的交互与数据流程，复用现有基础（推荐） | 对照参考重做票根制作与旅行行程，复用 Flutter、高德、账号及已有照片/地点关系 | 需要核验旧接口和数据迁移；要分别完成视觉、功能、失败恢复和真机验收 |
| 全量扩展为照片设计室＋AI 旅行平台 | 覆盖更多专业创作与自动规划能力 | 工作范围、外部服务、成本和协作复杂度明显增加，必须单独确认纳入范围 |

两套地图都使用高德，目前差异主要在行程与交互组织。现有 App 不需要仅因参考产品使用不同前端框架就整体更换技术栈。票根需要可编辑的内容与样式，地图需要按天和顺序组织地点，不能只添加背景颜色或装饰连线。

**五、从确认到交付的工作流程**

| 阶段 | 具体工作 | 用户可检查的产物 | 通过条件 |
|---|---|---|---|
| 0. 澄清并收口范围 | 回答本报告的决定项；只补查影响本期的未知规则；解决必要测试会话和服务依赖 | 修订后的范围、功能清单、未知项与依赖清单 | 没有影响主流程的未决产品选择；明确哪些内容本期交付 |
| 1. 定义界面与操作 | 对照竞品真机截图，给出主要页面、材质、布局与操作状态；明确点击、横滑、翻面、编辑和地图手势 | 使用真实照片质感的示意图、操作分镜、状态对照；明确标注示意图与真实运行截图 | 每个核心入口能顺着图走到保存/收藏；视觉审批顺序按用户所选执行 |
| 2. 核查现有工程与数据 | 读取实际前后端；服务器以 live 快照核对；检查旧 trips/routes、照片样式及共享关系；准备备份和迁移回滚方案 | 复用与替换清单、接口差异、迁移前后核对项 | 不以旧本地副本冒充线上实况；原有记录可保留、迁移可撤回 |
| 3. 完成一个端到端闭环 | 优先做“选内容→编辑→保存→重新打开”，以及“建行程→安排地点→地图路线→保存恢复” | 可在测试环境运行的完整主流程 | 保存有反馈，失败保留输入；重新进入能恢复；界面展示与实际数据一致 |
| 4. 扩展确认范围内的能力 | 完成12套成像、20款相纸、8款票根模板，裁切、记录、收藏、相纸手绘和背面记录；补齐按天编辑、排序、跨日移动、交通方式、删除与共享 | 功能与验收条款逐项对应的版本 | 不用占位按钮或假数据冒充完成；全部纳入的操作都有成功与异常规则 |
| 5. 验证与修复 | 静态分析、必要的模型/状态/接口回归；荣耀真机逐页操作；需要时双会话；深浅模式、权限、失败与性能检查 | 问题清单、修复证据、截图和实测边界 | 现有及新增必要测试通过，analyze 无问题；核心流程无未处理的阻断缺陷 |
| 6. 发布和核验 | 固定版本及更新说明；按发布规程构建、提交/推送、上传；核对版本元数据、APK 校验、旧版升级提示与新版检查 | 可更新的正式版本、发布记录、回滚点 | 手机可获取新版本，下载校验与更新提示正确；报告写明实际测试边界 |
| 7. 关闭目标 | 对照验收清单核查每一项，说明剩余非目标内容和已知限制 | 最终交付报告 | 目标内没有尚未完成的必要工作；不得用预算或时间消耗代替完成判定 |

本期包含三个模块。先设计拍立得与票根的照片/编辑边界和旅行关联，再按依赖完成内容选择与持久化、拍立得/票根制作、逐日行程与路线、双人共享和整体真机验收，不预先承诺一个通用大编辑器。

**六、拟采用的验收标准**

| 方面 | 需要看得见的验收结果 |
|---|---|
| 参考一致性 | 用选定页面和真机截图对照主要布局、层级、相纸/票面质感与关键反馈；逐条记录差异，不笼统声称“一模一样” |
| 票根内容 | 用户能选择此次纪念的内容和照片，修改文字/日期/样式；不会将模板默认地点和编号误作真实记录 |
| 编辑与保存 | 保存中禁止重复提交；取消/退出有明确规则；失败保留工作；已保存作品按确认范围继续编辑 |
| 导出 | 导出成品与预览一致，不含工具条或选择框；相册保存失败与文件保存成功分别反馈；格式和尺寸有实际文件核验 |
| 行程与路线 | 每日地点、顺序、编号、卡片和地图保持一致；排序/移动/删除后旧路段失效，所需新路段重算；规则明确交通方式是否继承 |
| 状态恢复 | 返回、进程重启和重新加载后不丢失已保存记录；断网失败不假装成功，不抹掉输入 |
| 双人数据 | 若纳入双人共享，两会话能看到正确记录；同时修改的冲突规则明确；不能把单账号截图写成双人联调完成 |
| 旧数据 | 现有照片、地点和记录仍可访问；迁移前后数量及关键关联有核对；发现问题可回滚 |
| 可读性与交互 | 窄屏、长文本、空态、加载、错误、禁用状态可用；手绘与翻页、地图与面板手势互不误触 |
| 性能 | 在荣耀真机检查照片加载、长列表、地图切换和连续操作；用实际测得的数据报告，缺少完整原生帧数据就不声称达到某 FPS |
| 发布 | 服务器版本元数据、中文更新说明、下载文件、旧版本升级提示及新版本检查一致 |

更细的测试数量和性能样本在方案明确后依据实际实现确定；不沿用项目旧文档里的过期测试总数作为本次完成证据。
