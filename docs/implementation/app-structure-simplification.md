# App 结构精简

2026-10-23 用户确认：暂停视觉改版，优先两个人的日常与回忆，同时保留生活和旅行的独立入口。

## 已确认设计

- 底部固定五项：今天、回忆、旅行、生活、我们。
- 今天保留近况、每日一问、待处理事项与真实回忆；移除固定的课程、账本、旅行概览，避免示例内容和重复入口。
- 回忆集中相册、时光轴、心情、美食手账、慢信和报告；月度与年度报告通过同一入口选择。每日一问仍可从此回看。
- 旅行保留地图、清单和票根；地点详情突出照片与故事，编辑为次操作，路线、票根和删除收进更多。未实现的记账快捷按钮移除，已有表单记账链路保留。
- 生活改为工具列表：待办、记账、课程、衣橱、情侣厨房；经期记录仅原始女方身份可见，页面内部权限保护继续生效。
- 我们集中双方资料、伴侣绑定、纪念日管理、奖励兑换与设置。相册、报告等移至回忆；爱心豆集中到奖励区。
- 移除导出占位、假重置及未接通的业务提醒开关；保留通知总开关、App 内通知中心、清缓存、退出登录和诊断能力。
- 沿用现有主题、拍立得和票根组件；不删除业务记录，不迁移数据，不新增服务端聚合接口，不改衣橱内部流程。

## 实施与验收

1. 主导航使用命名目标，统一首页与通知跳转，防止重排后进入错误模块。验证五个入口可用，旅行通知仍到旅行。
2. 集中回忆入口，生活工具改为独立页面，缩短我们菜单。验证原功能仍可访问，女方私密入口不被男友端或开发者视角切换暴露。
3. 精简今天与旅行操作，清理占位设置。验证空待办不会显示两项，完成数量计算正确，未实现功能不冒充可用。
4. 补充导航、权限和按钮行为回归；analyze、全套 Flutter 测试、release 构建。用模拟器检查实际布局与深浅两态，明确真实账号、双端同步和原生地图的测试边界。
5. 递增版本、提交推送并按发布规程直接发布，核验旧版本升级、新版本不重复提示、中文说明及 APK 散列。

## 自查

本批次只移动既有功能入口并修正误导行为。保留原有服务端权限与记录关系。历史未接入的独立聊天、倒计时、愿望代码不因本批次顺便删除；其他解析、认证和厨房异常问题留在既有审计清单。
