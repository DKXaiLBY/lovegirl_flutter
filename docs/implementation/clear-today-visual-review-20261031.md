## 本轮修正与回归

- 首页原先在完成失败后只恢复原始列表，显示模型计数和条目未恢复；连续点击还会向服务器切换两次。现保留行并显示待处理，成功才更新计数，失败提示并可重试。行交互区域至少48逻辑像素，不再用独立的本地勾选状态冒充保存成功。
- 首页Provider随账号清空，旧请求不写回新账号；照片和伴侣请求也校验账号/请求代次。旧相册与已发布拍立得的原图共同作为封面来源，返回制作页面后刷新，保留旧相册权限。
- 旧照片空白相纸字不再吞掉非空说明。当年当天稍早拍的照片不再生成“0年前的今天”，照片和足迹均遵守已有的“候选年早于当年”规则。
- 记录按钮直接打开既有的拍摄/相册来源选择。真机已打开、取消、返回并保留QA原照片和草稿状态；本轮没有把入口验证写成完整制作/发布闭环重新验收。
- 在带所有权标记的QA容器上暂时停止接口，实际点击手机待办，观察失败提示/原计数/原行；恢复容器后实际重试成功，并通过普通QA API确认及恢复测试条目。正式服务的进程启动时间未变，正式68表指纹与开工基线一致。
- 197项Flutter回归通过，analyze0；源文件、APK和原始截图散列见[清单](clear-today-honor-20261031/manifest.json)。内部包仍为187版本码、只连接loopback QA接口，没有自动登录或发布到正式下载渠道。
- Windows测试临时目录多次出现errno145清理失败，已单独提交 `df529d2`：验证解析后的父目录与测试名称前缀，只对测试自身目录的145错误最多重试200ms。草稿行为断言和App存储实现保持原样，其他错误继续抛出。
