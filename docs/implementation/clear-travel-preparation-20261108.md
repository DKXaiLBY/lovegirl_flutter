# LoveGirl 旅行准备

## 数据和操作边界

- 旅行准备引用已保存的行程。行程改名和改期后显示当前标题和日期，超出新日期范围的原搭配可继续查看和解除关联。
- 每日搭配只对本人可见，每天可引用一套已有穿搭或一至八件在柜衣物。衣物退役、删除或穿搭移除后保留可辨认的记录，禁用已失效的衣物照片链接。
- 个人行李以本人和行程为范围。共同物品以当前绑定和行程为范围，可分配给两人中的任意一人。双方用同一份版本化清单更新，提交过期版本时收到 409。
- 解绑会让原共同清单失去访问权限。重新绑定同一人后开始新的共同清单。原共同记录与个人记录保留。删除行程或失去行程访问权时，当前账号仍可查看其有权读取的归档。解除任何准备关联均保留衣橱和地点。
- 数据库变更为新增表与新增绑定轮次字段。服务端回滚可以恢复旧路由和挂载并保留增量表，用于重新启用时恢复资料。
