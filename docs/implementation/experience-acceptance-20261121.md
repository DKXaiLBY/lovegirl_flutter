### 存储、触觉和玻璃菜单

- 从 App 内检查更新、下载，在荣耀系统安装器完成隔离候选包升级。安装包占用由 127.7 MB 降至 0 B。照片缓存在升级后仍能读取。`exp-03-storage-before.png` 与 `exp-03-storage-after.png`。
- 缓存压力测试通过隔离只读代理下载 8 个 21 MiB 图像对象。4.6.0 早期包留下 189.0 MB，发现缓存库能去掉索引，但部分旧相对路径文件仍留在磁盘。补齐实际文件回收后，用同一台荣耀启动自动缩减至 86.9 MB。随后手工清理从 94.9 MB 降为 0 B，本机票根草稿始终为 355.9 KB。证据见 `exp-04-storage-after-restart-trim.png`、`exp-04-storage-before-clear.png` 和 `exp-04-storage-after-clear.png`。
- 清理后从收藏再次打开同一张草稿，原照片和留言可见，重开后涂鸦在同一区域的玫瑰色像素数与清理前同为 293。对照 `exp-04-ticket-draft-before-clear.png`、`exp-04-ticket-draft-restored.png` 和 `exp-04-ticket-note-restored.png`。

- 荣耀在设置中关闭触觉反馈，冷启动后保持关闭，随后恢复初始开启值。Flutter 渠道测试核验关闭后四种触觉强度均不再上报系统。
- 亮色 1.15 与深色 1.45 下打开数据管理、缓存确认和取消。沿回忆、票根收藏、继续编辑、文字与日期、选择日期进入深层菜单。实际截图包括 `exp-03-storage-confirm-dark-large.png`、`exp-03-ticket-fields-glass.png` 和 `exp-03-ticket-date-L5.png`。
