# 备考按页 AI 重识别

目标是让用户在读完讲义或试题 PDF 后，挑出本地识别有疑问的一页，核对原图和两份文字，确认后才用于讲义或复习题。界面沿用深蓝书刊主题和原来的试题、讲义入口。

回滚点为 `backup/before-study-ocr-20261124`，发布基线为 v4.8.2+198。旧安装包和当前源码备份均已核对。

## 验收标准

| 场景 | 应看到的结果 |
| --- | --- |
| 选择页 | 讲义、试题和答案页均可按页打开核对。无本地文字的页仍可打开原图。 |
| 云重识别 | 先确认发送范围，再发送当前页图。用受控接口核对请求和返回。配置真实供应商后，在同一批页图上另行测识别质量。服务端只接受已登录的同账号请求。 |
| 对照 | 手机通过「原页、本地、AI」切换。宽屏可以同看原图和文字。AI 文字可校对，识别失败仍可读到本地结果。 |
| 导入 | 采用一页后重新配对。涉及 AI 重识别的题需要逐题核对题干、选项和答案才能导入。 |
| 真机 | 用荣耀手机录入政治第一章样本，记录文字、答案表及匹配的差异，保存亮色、大字号、云端失败和成功对照的截图。 |
| 发布 | 保留上一版包，检查代码、Flutter、服务端与升级链路。区分替身接口测试与真实百炼质量测试。 |

文字初稿、题卡和作答在现有账号空间内保存。云识别由用户对当前页发起，返回原文草稿。

## 通用服务端模板

使用 [环境变量示例](../../server_fixes/study-ai.env.example)。文字出题与图像重识别分别配置地址、模型和凭据。DeepSeek 官方 `deepseek-flash` 支持两种任务的输入格式。其他兼容服务可分别替换 OCR 与 TEXT 配置。云端识别需要模型接受 JPEG 的 `image_url`，文字出题需要模型支持 JSON 输出。 [DeepSeek 视觉接口](https://api-docs.deepseek.com/guides/vision/) · [JSON 输出](https://api-docs.deepseek.com/guides/json_mode/)

将配置注入 LoveGirl 服务进程环境后重建容器。每个角色的地址、模型和密钥齐全才显示可用状态。客户端根据实际服务名称提示发送范围。选定的页图在请求中传送，LoveGirl 的识别路由不保存页图。应用的导入入口仍可核对本地识别。
