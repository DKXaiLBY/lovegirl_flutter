# LoveGirl UI 参考图还原设计规范

基准图：`C:\Users\DKX\Downloads\首页B回忆票根版.png`

这份规范的目标不是“做成粉色情侣 APP”，而是把参考图里的气质稳定落到整套 APP：像一份给她准备的专属菜单、旅行票根和生活手账。后续实现时，所有页面都按这里执行。

## 1. 全局视觉方向

- 气质：温暖、精致、专属、轻生活，不幼稚、不办公、不花哨。
- 核心隐喻：票根、菜单、便签、小账本、旅行手账。
- 背景：暖白纸感，不能用纯白大平面，也不能用大面积粉色。
- 主色：珊瑚红用于当前状态、主按钮、强调数字。
- 辅色：鼠尾草绿用于旅行、课程、完成状态。
- 点缀：豆子金用于爱豆，浅橘用于待接单/提醒。
- 卡片：浅暖白底、细描边、柔和阴影，圆角中等，不能变成普通 Material 大圆卡。
- 字体：标题要有温柔但清晰的重量，正文保持干净易读；所有界面必须中文优先。

## 2. 首页

首页必须最接近参考图，是全 APP 的设计母版。

- 顶部：
  - 左侧是 `LoveGirl` 大标题，旁边可有小爱心点缀。
  - 第二行显示 `我们在一起的第 X 天`，数字用珊瑚红突出。
  - 右侧是天气与爱豆，不做大卡片。天气显示温度、天气、体感温度；爱豆显示豆子图标、数量和 `爱豆`。
- 今日照顾卡：
  - 大卡标题 `今天想照顾的事`，副标题 `爱是把小事，放在心上`。
  - 卡片右上角可以放花束/信封类柔和插画或等效装饰，不能用老土功能图标。
  - 内部双栏：左侧投喂她，右侧待办清单。
  - 投喂她展示最近/推荐商品、价格、接单状态、男友头像/昵称、`去看看` 按钮。
  - 待办清单展示 1-2 条具体任务、完成进度、绿色 `新增一件事` 按钮。
- 回忆票根：
  - 左侧是真照片或照片占位，中间是 `3 个月前的今天`、地点、回忆文案。
  - 右侧是年份、日期、节日/标签、`生成回忆票根` 按钮。
  - 票根边缘要有打孔/撕票感，不能只是普通横向卡片。
- 旅行计划票根：
  - 左侧显示旅行名、说明、参与人头像、状态。
  - 右侧显示日期范围、天数、计划进度、`查看路线` 按钮。
  - 最右侧可加入竖向条码/LOVEGIRL TRIP 文本，强化票根感。
- 底部生活卡：
  - 左半是本月小账本：总支出、剩余预算、简洁饼图、`去记一笔`。
  - 右半是本周课程：下一节课、地点、节数、`查看课表`。
- 底部导航：
  - 图标必须简洁现代，当前项用珊瑚红填充。
  - 标签使用：首页、互动、发现、我的。若实际仍保留 5 Tab，需要视觉上合并成不拥挤的结构。

## 3. 投喂站

投喂站要像“她的专属菜单”，不是普通商城。

- 首页状态：
  - 顶部标题 `投喂站`，副标题表达“点下去是真的会叫我买”。
  - 顶部展示今日可投喂状态、最近订单、催单提醒，不堆统计数字。
- 店铺列表：
  - 店铺卡像菜单分组，展示店名、类型、常点标签、最近点过。
  - 她自己添加的想吃要有特殊标记，例如 `她想吃`、手写便签样式。
  - 不做全网抓取式商品海，重点是预配置常点 + 她临时想吃。
- 商品列表：
  - 商品卡要更精致，图片/图标占比更高，价格清晰。
  - 商品按钮文案用 `想吃这个`，不要电商化的 `加入购物车`。
- 下单弹窗：
  - 弹窗像点单确认小票，包含商品、数量、备注、预计真实金额、爱豆状态。
  - 爱豆不是拦截下单的余额，而是成就/心意记录，可提示“这次会消耗/获得多少心意感”，不阻止她点。
- 订单追踪：
  - 女友端看到：已发出、他已接单、准备中、配送中、已送达。
  - 男友端看到：接单、记录外卖平台、真实金额、订单备注、配送状态。
  - 催单按钮触发真实通知，同时 UI 要有节制反馈，防止连续狂点。

## 4. 旅行地图

旅行地图要像真实地图产品 + 旅行票根抽屉，不再像低质瓦片截图。

- 地图主屏：
  - 地图占主要空间，浮层控件放在地图上，不用卡片把地图包得很重。
  - 顶部浮层：搜索地点、城市/路线筛选。
  - 右侧浮层：定位、图层、路线、我的/她的标记开关。
  - 当前定位必须显示蓝点/方向/精度圈。没有定位权限时给清楚提示。
- 地点标记：
  - 我标的点和她标的点颜色不同，但同一个地点合并显示。
  - 两人都编辑过的地点显示双人小标记。
  - 点击标记后地图平滑移动，Marker 高亮，底部抽屉展开。
- 底部抽屉：
  - 抽屉使用票根风格，展示地点名、地址、天气、营业时间、交通方式、备注。
  - 两个人的备注分开显示，但不做复杂权限隔离。
- 路线规划：
  - 出发前路线用票根卡展示：日期、途经点、出行方式、预算、进度。
  - 地图上画路线折线，途经点有数字顺序。
  - 支持临时把多个想去地点串起来看顺不顺路。
- 旅行小票：
  - 打卡后可生成类似 Picslicer 票根风格的小票：照片、地点、日期、天气、花费、心情。
  - 小票可沉淀到时光轴、首页随机回忆、月度报告。

## 5. 生活/待办/记账/课程

生活模块要像两个人的小账本和计划本。

- 待办和愿望合并：
  - 主视觉像清单便签，不像项目管理工具。
  - 每条任务包含负责人、时间、状态、爱豆奖励。
  - 重要任务可在首页出现，但首页只展示 1-2 条。
- 记账：
  - 使用小账本视觉，金额清晰，类别用柔和图标。
  - 投喂订单、旅行花费可以自动同步过来，并标明来源。
  - 涉及金额的展示要克制，不做夸张财务仪表盘。
- 课程表：
  - 使用课程便签/时间轴，不做学校教务系统风格。
  - 首页只展示下一节课；完整页展示周视图和今日列表。

## 6. 互动页

互动页承接投喂、聊天、心情、纪念日这些“情侣互动”功能。

- 页面顶部展示今天的互动状态，例如投喂、心情、聊天提醒。
- 功能入口不要用九宫格堆满，应按重要程度分区：
  - 第一层：投喂站、私密聊天。
  - 第二层：心情日记、纪念日。
  - 第三层：相册、时光轴、倒计时。
- 每个入口像一张小卡片，有简短状态，而不是只有图标和标题。

## 7. 发现/回忆页

发现页应该更像回忆陈列馆。

- 包含旅行小票、相册、时光轴、随机回忆、月度报告。
- 卡片形态以票根、照片、便签为主。
- 时光轴不应只是列表，要有月份分组、照片缩略、自动生成条目。
- 月度报告可以用长图/报告卡形式，偏温柔总结，不做冷冰冰数据面板。

## 8. 我的页面

我的页面不放一堆无关功能，要像关系和账户的管理页。

- 顶部：
  - 两人头像、昵称、在一起天数、伴侣绑定状态。
  - 爱豆余额、签到状态、版本状态。
- 中部：
  - 关系设置：伴侣绑定、隐私、安全、通知。
  - 数据管理：备份、日志、版本更新。
  - 个性化：主题、首页偏好、地图偏好。
- 底部：
  - 当前版本、服务器连接状态、退出登录。
- 视觉：
  - 保持纸感卡片，但更安静，不做花哨装饰。

## 9. 经期管理

经期管理是敏感但实用的模块，风格要温柔、私密、清楚。

- 不使用刺眼红色大面积展示。
- 状态卡显示当前周期、预计日期、提醒。
- 记录入口要简单：症状、心情、备注。
- 可联动投喂站：经期期间推荐热饮/清淡食物，冰饮降权，但不强行隐藏。
- 数据安全提示要清楚但不吓人。

## 10. 私密聊天

聊天页要像两个人的小纸条。

- 消息气泡圆角柔和，但不要过度可爱。
- 顶部显示对方在线/最近消息状态。
- 可保留照片、语音、表情入口，但图标要现代。
- 重要消息可沉淀为时光轴，但必须由用户主动确认。

## 11. 相册/时光轴/纪念日/倒计时

- 相册：照片墙 + 票根相册，支持按旅行、月份、人物筛选。
- 时光轴：月份分组，自动条目和手动条目区分显示。
- 纪念日：修复所有乱码，日期卡片要清楚，临近 3 天可同步首页。
- 倒计时：不要单独做成一堆卡片，应和纪念日合并或作为纪念日子功能。

## 12. 实现验收标准

- 首页第一屏截图必须能明显对应参考图：顶部、今日照顾卡、回忆票根、旅行票根、账本课程卡都在正确位置。
- 所有主要文字必须是中文，不能出现英文占位或乱码。
- 天气体感温度不能超出卡片。
- 旅行地图点击地图模式不能闪退；失败时必须显示中文错误提示。
- 投喂站、旅行地图、我的页面必须各自延展同一套纸感/票根/菜单语言。
- 发布 APK 前必须完成：`flutter analyze`、release 构建、版本接口检查。
